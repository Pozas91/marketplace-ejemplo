# diagramas

| Comando | Qué hace |
|---|---|
| `/diagramas:mermaid <qué> [tipo]` | Diagrama Mermaid (flujo, secuencia, estados, ER, clases) y visor HTML local |
| `/diagramas:diagrama-flujo <proceso> [flujo \| secuencia]` | Diagrama de un proceso del código con tabla de fuentes `fichero:línea` |
